# Data Intelligence Enterprise Platform — V10.0.0

## Objetivo
A V10 introduz o instalador Windows unificado. O build oficial passa a produzir `DataIntelligence_Setup_V10.0.0.exe`, que apresenta exatamente seis perfis homologados:

1. PC SERVIDOR + PC CENTRAL
2. PC CENTRAL
3. PC SERVIDOR
4. PC CLIENTE + AGENTE
5. PC CLIENTE
6. PC AGENTE

## Comportamento por perfil
- **Servidor + Central**: instala Servidor Corporativo e aplicação desktop configurada como Central, apontando automaticamente para `127.0.0.1` na porta escolhida.
- **Central**: instala o desktop em papel `central` e solicita a URL do servidor.
- **Servidor**: instala apenas `DataIntelligenceServer.exe`, cria/verifica o administrador inicial, registra inicialização automática e regra de firewall Private/LocalSubnet.
- **Cliente + Agente**: instala desktop em papel `cliente` e o Agente TI provisionado.
- **Cliente**: instala apenas o desktop em papel `cliente`.
- **Agente**: instala apenas o Agente TI e registra sua inicialização automática.

## Persistência
Executáveis: `C:\Program Files\Data Intelligence`.
Dados mutáveis: `C:\ProgramData\DataIntelligence`.
A desinstalação remove executáveis/tarefas, mas não exclui automaticamente banco, configuração, logs, certificados ou backups.

## Segurança do bootstrap
Administrador e Agente TI usam arquivos temporários JSON durante o setup. A senha/token ficam em arquivos temporários separados e são excluídos após o provisionamento; a senha do administrador não é colocada diretamente nos argumentos do processo.

## Build oficial
`scripts/build_distribuicao_windows.ps1` continua gerando os binários PyInstaller e agora chama `scripts/build_setup_windows.ps1`, que exige Inno Setup 6 e produz o único instalador de distribuição.

O CI Windows instala Inno Setup, compila o `.iss`, verifica a existência do `Setup.exe` e publica o instalador como artefato.

## Limitação de ambiente
Este ambiente de trabalho é Linux e não possui o compilador Windows `ISCC.exe`; portanto o `Setup.exe` binário não foi fabricado localmente. A compilação real do instalador é obrigatória no job Windows do GitHub Actions ou em uma máquina Windows com Inno Setup 6, e o pipeline falha se `release\DataIntelligence_Setup_V10.0.0.exe` não for criado.
