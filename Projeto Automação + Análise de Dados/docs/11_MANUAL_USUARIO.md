# Manual do usuário

## Entrada

Abra a aplicação, escolha tema claro/escuro quando necessário, informe usuário e senha corporativos. Depois do login, a preferência do perfil é aplicada pelo servidor.

## Navegação

Use Módulos para acessar o departamento. Menus especializados mostram somente funções do domínio. Favoritos/atalhos antigos são normalizados para as seções atuais quando houver compatibilidade.

## Analytics

Comece por **Visão executiva**. Use **Insights** para ver situações ordenadas por prioridade e clique na ação recomendada para abrir o módulo responsável. **Alertas** concentra Críticas/Atenção. **Explorar dados** e **Análise externa** compõem o laboratório para Excel/CSV/Parquet/fontes externas.

## Integrações entre áreas

- Marketing pode enviar MQL/SQL para Comercial sem duplicar CRM.
- Estoque pode encaminhar reposição para Compras.
- Jurídico pode encaminhar provisão para análise Financeira sem criar lançamento automaticamente.
- Admissão/desligamento de RH acompanha etapas de TI, Estoque, Administrativo e Financeiro.

## Boas práticas

Não compartilhe senha, não use conta administrativa para rotina comum, não ignore alertas críticos sem justificativa operacional e prefira os fluxos integrados em vez de cadastro duplicado.
