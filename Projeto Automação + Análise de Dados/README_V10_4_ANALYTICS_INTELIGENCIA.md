# V10.4.0 — Analytics como Inteligência Empresarial

A Central Analytics foi reposicionada para responder primeiro **o que está acontecendo na empresa e o que precisa de atenção**. Os resumos dos nove módulos autorizados alimentam um cockpit executivo; cada insight registra origem, severidade, prioridade, métrica e ação de navegação para o módulo responsável.

O laboratório de dados continua aceitando análises externas/importações, mas deixa de ser o centro conceitual do produto. A navegação produtiva não anuncia IA Assistente ou MLOps enquanto não existir provider, credencial, autorização e ciclo de modelo homologados.

As estruturas `analytics_insights`, `analytics_regras` e `analytics_execucoes` foram adicionadas pela migration 024. O mecanismo isola erros por módulo para impedir que uma falha departamental derrube toda a visão executiva.
